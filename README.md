# thepremium-master — 2026년 11월 THE PREMIUM 통합 성적처리

## 업데이트 사항
- 학생 명부 메뉴: **전체 응시자 명부** 다운로드·수정·재업로드, **수정할 시트: `전체응시자명부`**.
- 기존 학생은 `학생ID(기존유지)`를 수정하지 마십시오. 이 ID로 3·5·7·8·9·10월 성적과 연결됩니다. 이름·학교·수험번호·전화번호는 정정할 수 있습니다.
- 신규 학생은 **시트 맨 아래에 추가**하고 학생ID 칸을 비워두십시오. 동명이인·전화번호 충돌은 자동 병합하지 않고 검사합니다.
- 교과별 OMR PDF 여러 페이지를 **한 번에 판독**합니다. 페이지별 한글 이름(초성·중성·종성) 후보, 수험번호·전화번호 입력값과 명부를 대조하고 **확인 후 확정**합니다. 실제 스캔본의 모든 이름이 자동 판독되는 것은 아닙니다.
- 국어/수학 OMR 선택과목 마킹, 탐구Ⅰ·Ⅱ OMR 과목번호 후보를 읽어 **11월 응시과목**에 연결합니다. 과거 선택과목 변경 가능. 코드·이름 불확실 시 검수 필수.
- 11월 과목별 정답·배점이 **검증·확정된 과목만** 원점수·10월 기준 잠정등급 산출.
- 1개 과목만 성적이 확정되어도 기존 **PDF 성적표 양식**으로 출력할 수 있습니다. 미채점 과목은 미확정으로 나타납니다.
- 기존 테스트 모드 및 OMR→필요 시 엑셀 `답안수정` 시트 수정·재업로드 기능 유지.

## GitHub / Streamlit 적용
1. 현재 DB를 `설정·로고·백업 → 모든 결과 JSON 백업`에서 내려받으십시오.
2. 저장소에서 `app.py`와 `template_omr.py`를 교체합니다. **기존 `reference/omr`, `requirements.txt`, `assets`를 유지**합니다.
3. 배포 전후에 **실제 운영 모드 데이터가 서버 재시작 시 사라질 수 있음**을 유념하고 JSON 백업을 보관하십시오.
4. 학생 명부·원본 OMR·성적 파일을 공개 GitHub에 올리지 마십시오.

## 확인된 범위 / 제한
- Python 코드 문법 검사 통과. 전체 응시자 명부 수정 XLSX 왕복(기존 이름 변경·신규 학생 추가) 테스트 통과.
- 기존 OMR 자동판독기는 이미지 위치 정렬 및 후보 판독이며 **실제 필기 OMR 전수 정확도는 검증되지 않았습니다**. 이름 마킹·수학 단답형·탐구 과목코드·중복/미표기는 원본 검수 후 확정해야 합니다.
- 웹 클라우드 실배포 테스트는 별도로 수행해야 합니다.
