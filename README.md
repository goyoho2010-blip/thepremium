# thepremium — OMR 학생 식별정보 검수 개선

## 적용
GitHub `thepremium` 저장소에서 `app.py`, `template_omr.py`를 이 ZIP의 파일로 교체하고 Commit changes를 누르십시오. 기존 정답·배점 데이터와 성적표 양식은 변경하지 않습니다.

## 검수 엑셀
1. OMR 판독·검수 → 교과별 PDF 업로드 → 전체 페이지 자동판독
2. `thepremium-omr-review.xlsx 다운로드`
3. `판독검수` 시트에서 다음을 확인합니다.
   - D: OMR 마킹에서 읽은 이름 후보 (틀릴 수 있음)
   - E: 명부와 전화번호·수험번호를 대조한 학생명 후보 (검수 후 확정)
   - F: OMR에서 읽은 전화번호 숫자 (010을 제외한 8자리)
   - G: OMR에서 읽은 수험번호 6자리 (기존 명부가 4자리면 뒷자리 비교)
   - `?` 표시: 해당 자리 판독 불확실, 원본 대조 필요
4. `원본확인` 시트에서 각 PDF 페이지의 수험번호·전화번호·학생명 마킹 부분을 확대해 눈으로 확인합니다.
5. `판독검수` 시트의 틀린 학생명·전화번호·수험번호를 수정하고 검수확인(Y)=Y를 입력한 후 업로드합니다.

**중요**: 원본과 대조하기 전에는 어떤 후보도 확정된 학생정보로 취급하지 않습니다. 전화번호 또는 수험번호 마킹이 비어 있는 OMR은 자동 식별할 수 없습니다.

개인정보가 포함된 검수 엑셀은 GitHub에 업로드하지 마십시오.
