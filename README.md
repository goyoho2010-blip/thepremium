# THE PREMIUM – PDF 전체 판독 → 엑셀 검수 → 재업로드 정산

## 설치 및 업데이트
GitHub `thepremium` 저장소에서 `app.py` 및 `template_omr.py`를 교체하고 `reference/` 폴더를 유지하십시오. `reference/thepremium-answers-11.xlsx`를 추가하십시오. 기존 `requirements.txt`는 유지합니다. 학생 개인정보가 담긴 엑셀·OMR은 공개 저장소에 올리지 마십시오.

## 기본 사용 절차
1. **11월 정답·배점** 메뉴에서 포함된 `thepremium-answers-11.xlsx`를 원본과 대조한 뒤, `11월 정답 엑셀 검증 후 등록` 버튼으로 확정하십시오.
2. **학생 명부** 메뉴에서 기존 명부와 신규 응시자를 엑셀로 등록하십시오.
3. **OMR 판독·검수** 메뉴에서 교과별 PDF를 올려 `전체 페이지 자동판독`을 클릭합니다.
4. `thepremium-omr-review.xlsx`를 내려받습니다. `판독검수` 시트에서 원본 마킹과 이름, 전화번호, 수험번호, 실제 11월 선택과목, 1~45번 답안을 확인/수정합니다. 미표기는 **공란**을 유지합니다(오답·0점).
5. 정답을 확인한 각 행 `검수확인(Y)` 칸에 **Y**를 입력합니다. 제외할 행의 `처리(Y/제외)`에는 **제외**를 입력합니다. 잘못 인식된 선택과목을 바꿀 때는 마지막 열 `선택과목정정사유`에 원본 대조 이유를 기록하십시오.
6. 수정 엑셀을 같은 화면에 재업로드합니다. 오류가 없으면 검수확인 체크 후 `검수 엑셀 확정 업로드 · 11월 자동 정산`을 클릭합니다.
7. **학생 성적표**에서 기존 A4 PDF 및 월별 등급 그래프를 출력하십시오. 한 교과만 확정해도 해당 과목의 점수가 표시됩니다.

## 주의 사항
- 검수 엑셀의 열 이름과 열 순서를 변경하지 마십시오.
- 명부에 없는 학생은 `학생 명부`에서 추가한 다음 엑셀을 다시 업로드하십시오.
- OMR 이름 자동판독은 참고 후보입니다. 실제 마킹된 이름과 다른 경우 검수 엑셀에서 반드시 수정하십시오.
- 국어·수학 및 탐구 선택과목 후보가 잘못 인식될 수 있으므로, 실제 OMR 과목 마킹과 일치하는지 최종 확인하십시오.
- 수학 단답형은 숫자 전체를 검수하고, 정답 `0`과 미표기 공란을 구별하십시오.
- 정답 원본 16장에서 전사한 `thepremium-answers-11.xlsx`는 **최종 원본 대조 전 1차 데이터**입니다. 원본 검증 체크 후에만 확정 등록하십시오.
- 테스트 모드는 실운영 데이터와 분리됩니다. 서버 임시 저장은 영구 보장되지 않으므로 확정 후 JSON 백업을 다운로드하십시오.
