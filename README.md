# THE PREMIUM · 2026년 11월 통합 수정본

## 이번 수정

- 기존 **성적표 디자인·로고·그래프 유지**.
- **신규 응시자 등록:** `학생 명부` → `thepremium-roster.xlsx 양식 다운로드` → **`11월신규명부` 시트**에 이름/학교/학년/수험번호/전화번호/선택과목 기입 → 엑셀 업로드 → 중복·충돌 검증 → 명부 반영. 과거 성적은 신규 학생에게 생성하지 않습니다.
- 기존 명부에 이름이 일치하는 학생은 기존 기록과 연결합니다. 같은 이름이 중복되거나 수험번호·전화번호가 다른 학생에게 연결되면 자동 병합하지 않고 경고합니다.
- **수학 단답형:** 16~22번, 29~30번의 백/십/일 자리 숫자 마킹 중심을 실제 인쇄 양식에 맞게 재교정했습니다. 각 자리의 숫자 0과 빈 마킹은 별개이며, 원본 검수가 필수입니다.
- **탐구Ⅱ:** 답란 첫 선택지 좌표를 실제 양식에 맞춰 수정하여 ⑤번을 놓치는 사례를 줄였습니다. 실물 화학Ⅰ 5,6,17,18번은 재확인 대상입니다.
- **전교과 미표기:** 미표기 문항은 답안값을 빈칸으로 유지하고, 채점 시 오답·0점으로 처리합니다. 수학의 정답 숫자 `0`과 혼동되지 않도록 내부적으로 `0`으로 덮어쓰지 않습니다. 판독실패/중복·불확실은 미표기와 달리 검수해야 합니다.
- 기존 `엑셀 답안수정` → `답안수정` 시트 정정·재업로드는 그대로 유지.
- 3~10월 기존 성적 엑셀을 다시 업로드해도 신규 응시자 명부를 유지합니다.

## 배포

GitHub 저장소의 `app.py`, `template_omr.py`를 교체하고 기존 `reference/omr` 기준 이미지와 `requirements.txt`를 유지하십시오. 비공개 학생 명부·성적 자료는 공개 GitHub에 업로드하지 마십시오. 클라우드 데이터는 재시작 시 손실될 수 있어 JSON 백업이 필요합니다.

## 시험 범위 및 제한

기준 OMR 양식에 합성 마킹(90도 회전 포함)을 적용한 교과별 자동판독 시험을 통과했습니다. 이는 실제 학생 스캔본의 100% 정확도나 실서비스 배포 성공을 입증하지 않습니다. 수학 단답형과 탐구 과목명 및 미표기 여부는 시험 전 테스트 모드에서 실제 OMR을 대조하십시오.
