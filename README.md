# thepremium — OMR 자동판독 + 엑셀 선택 수정 통합판 (2026-11-06)

## 핵심 변화

- **OMR 자동판독은 기존과 동일한 기본 절차입니다.** 변경이 필요하지 않으면 엑셀을 열거나 업로드할 필요가 없습니다.
- 11월 응시 선택과목을 학생의 3~10월 이력에 기록된 선택과목과 **독립적으로** 보관합니다. 과목이 바뀌어도 11월 실제 응시과목을 지정하여 채점·잠정등급을 산출합니다.
- OMR 판독 화면에서 학생명, 전화번호, 수험번호를 입력하여 명부와 매칭할 수 있습니다. 필기 OMR에서 이름/번호를 자동으로 읽는 OCR 기능은 포함되지 않습니다. 동명이인이나 식별정보가 충돌하면 매칭을 보류합니다.
- 학생 명부에서 전화번호와 11월 수험번호를 수정·저장할 수 있습니다.
- **사이드바 `엑셀 답안수정` 메뉴**: `thepremium-answer-edit.xlsx` 다운로드 → **`답안수정` 시트만 수정** → 업로드·검증 → 승인 후 11월 해당 학생·교과만 재정산.
- `답안수정` 시트: 학생번호/학생명/전화번호/수험번호/학교/영역/11월 응시과목/판독 답안 1~45번/참고 점수/예외적 점수직접수정/수정사유 등이 포함됩니다. 적용할 행에 **Y** 표시가 있어야 반영됩니다.
- 점수직접수정은 예외적 수기 정산이며 **수정사유 필수**입니다. 11월 성적표 원점수와 잠정등급에 반영하되, 답안 정오답과 점수의 일치 여부는 별도로 검수해야 합니다.
- 이전 3~10월 자료와 PDF 성적표 디자인, 기관 로고, 월별 등급 변화 그래프는 유지합니다.

## 작업 순서

1. 시험 종료 후 교과별 PDF를 업로드하여 자동 판독합니다.
2. 각 페이지 학생 이름·전화번호·수험번호를 확인해 연결하고 응시 선택과목·마킹 결과를 검수 후 확정합니다.
3. **수정할 항목이 없으면 그대로** 성적표 생성·PDF 인쇄·저장을 진행합니다.
4. 오류를 발견한 경우 `엑셀 답안수정` → 다운로드 → `답안수정` 시트의 해당 행에 Y 입력 및 답안·과목·점수 수정 → 파일 재업로드 → 미리보기 후 승인합니다.
5. 성적표에서 자동 반영을 확인하고 **JSON 백업**을 내려받습니다.

## 배포

기존 GitHub `thepremium`의 **`app.py`만 교체**하면 됩니다. `template_omr.py`, `reference/omr`, 로고는 기존 정상 판독 버전을 유지하십시오. Cloud 재배포 후 관리자 비밀번호로 접속해 메뉴를 확인하십시오.

## 보안/검증

- 공개 GitHub에 학생 OMR/전화번호/성적/백업 엑셀·JSON을 올리지 마십시오.
- Streamlit Cloud의 로컬 파일 저장은 영구적이지 않습니다. 개인정보를 저장하는 운영환경에는 접근통제, 별도 데이터 보관과 백업 절차가 필요합니다.
- 엑셀 업로드는 **일괄 검증**됩니다. 오류가 하나라도 있으면 아무 행도 적용하지 않습니다.
- 구문 검사와 예제 엑셀 내보내기→수정→업로드·점수 재계산 검증 통과. 실제 Streamlit Cloud 배포 테스트는 미완료입니다.
