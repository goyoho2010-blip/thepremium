# THE PREMIUM 성적처리 NAVI — 명부 엑셀 덮어쓰기 개선

## 이번 수정
- [학생 명부]의 **전체 응시자 명부 · 엑셀 덮어쓰기/추가**에서 두 종류의 엑셀을 자동 구분합니다.
  - `전체응시자명부`: 기존 학생의 이름/학교/전화번호/수험번호 수정·갱신 및 신규 학생 추가
  - `11월신규명부`: 기존 학생의 이름/식별정보로 연결하고 새 응시자 추가
- 명부 검증 요약을 표시하고, 확인 후 **검증한 엑셀로 학생 명부 덮어쓰기·추가**를 눌러 반영합니다.
- 파일에 없는 기존 학생을 일괄 삭제하지 않습니다. 3~10월 성적과 11월 확정 OMR 성적은 변경하지 않습니다.
- 기존 학생의 고유 학생ID를 변경하지 마십시오. 동명이인/식별정보 중복은 오류로 막습니다.

## 사용 방법
1. 기존 앱의 `설정·로고·백업`에서 전체 JSON 백업 다운로드
2. GitHub 저장소에서 이번 ZIP의 `app.py` 교체
3. Streamlit 재배포 후 로그인 → [학생 명부]
4. `thepremium-roster-all.xlsx`를 내려받아 `전체응시자명부` 수정, 또는 이미 가지고 있는 `11월신규명부` 양식을 그대로 업로드
5. 명부 검증 내용을 확인하고 [검증한 엑셀로 학생 명부 덮어쓰기·추가] 클릭

## 주의
- 학생 개인정보가 포함된 엑셀 파일을 공개 GitHub에 올리지 마십시오.
- 공개 Streamlit Community Cloud는 서버 재시작 시 로컬 저장정보가 사라질 수 있으므로 작업 후 JSON 백업을 별도로 보관하십시오.
- 학생 명부 교체는 확정 점수를 자동 생성하지 않습니다. 정답등록/OMR 답안 검수·확정이 필요합니다.
