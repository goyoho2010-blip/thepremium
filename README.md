# thepremium - OMR 판독 개선 (2026-11-06)

이 버전은 GitHub/Streamlit 용입니다. `app.py`, `template_omr.py`, `requirements.txt`, `reference/omr`, `assets` 폴더를 업로드하세요.

## 변경사항
- OMR 용지 정방향 자동 회전 및 기준 양식 투시 정렬 유지
- 각 선택지 주변 ±3픽셀 보정 탐색
- 옅은 연필 마킹의 명도와 빈 양식 대비 검출
- 인쇄된 붉은 원과 중성색 검은 연필 마킹 구별
- 미표기 과다 발생 시 원본 검수 경고 유지
- 테스트 모드 및 교과별 PDF 일괄 판독, 성적표 기능 유지

## 반드시 확인
실제 학생 답안 PDF 전체에서의 정확도 검증은 아직 완료되지 않았습니다. 제공된 테스트는 기준 이미지 위에 합성 마킹을 생성해 수행했습니다. 확정 전 학생별 검수는 필수입니다. 특히 수학 단답형은 수동 검수가 필요합니다.

개인정보 및 실제 성적 파일은 공개 GitHub에 올리지 마십시오.
