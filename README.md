# THE PREMIUM 11월 성적처리 — 최근 3개 학년도 수능 원점수컷 참고등급

## 변경사항
- 기존 11월 OMR 판독, 검수 엑셀, 11월 정답표, 원점수 및 3~10월 누적 성적 유지
- 11월 잠정등급: **2024·2025·2026학년도 수능 원점수 참고컷별 등급의 중앙값**
- 영어·한국사는 절대평가 고정컷 유지
- 10월 더프 등급은 전월 대비 성적 비교 자료로만 사용
- 기존 A4 성적표 레이아웃 유지. PDF에서 추정 기준 문구만 수정
- 11월 정답·배점 메뉴 맨 아래: `3개년 수능 등급컷 검증용 엑셀 다운로드` 및 수정 재업로드 기능
- 성적표 페이지에 연도별 참고등급 및 산출 근거 표 추가
- 3개년 등급컷 미확인 구간에는 **검증중** 표시하고 임의 등급 산출 금지

## 자료의 한계 / 필수 확인
수능 공식 등급은 국어·수학·탐구에서 표준점수로 결정됩니다. 원점수 등급컷은 입시기관의 역산 참고 자료입니다. 이 프로그램은 공식 수능등급 예측기가 아니며 11월 더프의 시험난이도 보정도 하지 않습니다.

기본 제공 3개년 자료는 부분 검증본입니다. 국어·수학 2024년·2025년 1~8등급 참고컷, 2026년 1~4등급 참고컷, 영어·한국사 고정컷이 입력되어 있습니다. **탐구 전 과목과 2026년 국수 5~8등급 구간은 공란**이며, 공식 표준점수로 채우면 안 됩니다. 참고자료를 검증해 엑셀에 입력 후 앱에서 업로드해야 해당 구간의 추정등급이 출력됩니다.

## 적용
1. 기존 Streamlit `설정·로고·백업` 메뉴에서 JSON 백업 다운로드
2. ZIP 내부 `app.py`, `reference/three_year_cuts.json`, `reference/thepremium-csat-3years.xlsx`를 기존 GitHub 저장소에 반영
3. `reference/omr`과 기존 로고 파일, 학생 답안 기록은 유지
4. Streamlit 재배포 → 정답·배점 메뉴에서 컷 자료 확인·필요시 수정 업로드 → 학생 성적표 확인
5. **실제 학생 개인정보 포함 파일을 공개 GitHub에 업로드하지 마십시오.**
