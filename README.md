# thepremium — 11월 정답표·OMR 일괄 업로드 수정판

## 변경 내용
1. **11월 정답·배점** 메뉴 맨 앞 배치.
2. 사용자가 제공한 11월 정답 이미지 16장을 `reference/november-answers.zip`에 포함하여 앱의 원본 확인 화면에서 조회 가능. 이 이미지는 **검증용 참고자료**이며, 문항별 정답/배점 텍스트로 자동 전사되어 있지 않습니다.
3. 선택과목별 정답/배점 편집, CSV 양식 다운로드·불러오기, 1~N 문항 번호·정답 형식·배점 합계 검증, 국어·수학 공통문항 일치 검증 및 저장.
4. 확정 전 정답으로 점수가 산출되지 않도록 제한.
5. 전체 학생 OMR PDF를 먼저 올리고 페이지별 학생·교과 연결. 회전 보정, 마킹 좌표 보정, 판독값 수정 후 확정.
6. 기존 월별 등급 그래프, 한국어 PDF 성적표, A4 인쇄, 전체 PDF/엑셀 저장 기능 유지.
7. 이전 소스의 들여쓰기 및 미등록 모듈 문제 수정, 수정된 3~10월 성적 엑셀은 앱에서 별도 업로드.

## 배포 방법
- 압축을 풀고 모든 파일 및 하위 폴더를 GitHub `thepremium` 저장소에 업로드합니다. `reference/november-answers.zip`도 업로드해야 정답 원본 이미지를 앱에서 확인할 수 있습니다.
- GitHub가 공개(Public)인 경우 `data/work.json`, 학생 성적 `.xlsx`, 학생 OMR 등 개인정보 파일을 **절대로 저장소에 올리지 마십시오**.
- Streamlit Community Cloud에서 `app.py`를 실행합니다. Secrets에 `APP_PASSWORD = "강력한 관리자 비밀번호"`를 등록합니다.
- 배포 후 학생 명부 메뉴에서 이전 월별 성적 엑셀을 업로드합니다.
- 정답을 선택과목별로 입력·검증한 뒤 학생 OMR 업로드·답안 판독을 진행합니다.
- 기존 앱에 실제 입력된 결과가 있다면 **교체 전에** `설정·로고·백업`에서 JSON 전체 백업을 내려받으십시오.

## 검증 제한
- 문항별 정답과 배점은 아직 16장 이미지에서 확정 추출된 데이터가 아닙니다. 관리자 대조 입력·확정 전에는 채점이 수행되지 않습니다.
- OMR 페이지에서 학생 이름·교과를 자동 인식하지 않습니다. 페이지별 선택·검수가 필요합니다.
- 11월 등급은 10월 원점수 컷 적용 잠정 참고치입니다.
- Streamlit 무료 서버의 디스크는 영속적 개인정보 저장소가 아닙니다. 개인 정보 업로드의 법적·기관 운영 규정을 확인하고 암호 보호된 백업을 별도로 보관하십시오.
- Streamlit Cloud에서 실제 OMR 장비/용지별 좌표 판독은 실사용 테스트 전입니다.
