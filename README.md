# thepremium-simple — 11월 더프 OMR 간편판독

## 적용 방법
1. 이 ZIP을 압축 해제하고 **내용물**을 GitHub `thepremium` 저장소에 업로드합니다. 기존 `app.py`와 `requirements.txt`를 교체하고 **`template_omr.py` 및 `reference/omr/` 폴더 5장**을 함께 추가해야 합니다.
2. Streamlit Cloud가 변경사항을 재배포하면 로그인합니다.
3. `테스트 모드` → `OMR 판독·검수` → **전체 OMR PDF 업로드** → 페이지/학생/교과 선택 → `이 페이지 OMR 자동판독` → 판독표 가져오기 → 답안 확인 및 확정 순서로 사용합니다.
4. 시험을 마친 뒤 `테스트 데이터 전체 초기화`를 누르면 실전 성적은 보존하고 테스트 기록만 초기화합니다.

## 간편판독 원리와 범위
- 첨부하신 대성 THE PREMIUM **기준 OMR 5종**을 템플릿으로 제공하며, OpenCV 특징점 매칭으로 PDF/이미지 방향·위치를 자동 보정합니다. 수동 좌표 슬라이더를 제거했습니다.
- 국어 45문항, 영어 45문항, 한국사 20문항, 탐구 1·2 선택 각 20문항의 객관식 원을 판독합니다.
- 수학은 **1~15번과 23~28번** 객관식을 우선 판독하고 **16~22번, 29~30번 단답형**은 수동 검수 대상으로 남깁니다. 추후 실제 OMR로 단답형 판독을 검증하기 전에는 자동 전사하지 않습니다.
- 스캔 해상도, 필기구, 비뚤어진 촬영, 일부 잘린 OMR은 인식에 실패할 수 있습니다. 결과를 **자동 채점 확정하지 않고** 반드시 검수 후 확정합니다.
- 학생 식별(성명·수험번호)과 선택과목은 현재 자동 확정하지 않습니다. PDF 페이지별 학생과 교과를 연결해 주십시오.
- **11월 정답·배점은 원본 이미지가 포함되었을 뿐 숫자 데이터가 전부 확정된 것은 아닙니다.** 관리자 검증·확정이 완료된 교과만 성적을 산출합니다.
- GitHub 저장소가 공개인 경우 개인 성적 파일, OMR 원본, 실제 학생 이름·학교 데이터를 업로드하지 마십시오. 앱 비밀번호는 공개 저장소에 두지 말고 Streamlit Secrets에 등록하십시오.
- Streamlit Community Cloud 서버의 `data/work.json`은 영구적·다중사용자 안전 데이터베이스가 아닙니다. 운영 중에는 반드시 JSON 백업을 내려받으십시오.

## 설치 라이브러리
`pip install -r requirements.txt`

## 참고
이번 버전은 템플릿 자동 정렬과 모의 마킹 이미지에 대한 기능 검사를 거쳤으나, **실제 학생의 스캔 PDF로 판독률을 검증하기 전인 시범 버전**입니다.
