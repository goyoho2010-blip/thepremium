# thepremium-subject — 교과별 OMR PDF 일괄 업로드

## 변경된 처리 방식
- 교과별 묶음 PDF를 각각 업로드합니다: 국어 PDF(학생별 1페이지씩), 수학 PDF, 영어 PDF, 한국사 PDF, 탐구 PDF.
- 교과를 먼저 선택한 뒤 **전체 페이지 자동판독** 버튼 한 번으로 해당 PDF의 모든 페이지를 읽습니다.
- 한 페이지를 한 학생의 해당 교과 답안지로 처리합니다. 탐구 용지 한 장은 탐구Ⅰ과 탐구Ⅱ 영역으로 분리 판독합니다.
- 전체 판독 목록에서 각 페이지를 선택하고 학생을 확인/연결한 뒤 마킹을 검수합니다.
- 검수 완료 기록만 저장되며, 다음 교과 PDF를 같은 방식으로 처리합니다.
- **학생 성명과 수험번호 자동 인식은 아직 구현되지 않았습니다.** 수학 단답형은 직접 검수해야 합니다.
- 11월 정답·배점을 채점용 값으로 확인·확정하기 전에는 정확한 점수 산출이 불가능합니다.
- 실제 운영과 테스트 모드를 구분하고, 테스트 모드에서는 운영 데이터에 반영하지 않습니다.

## 배포
ZIP 압축을 풀고 내부의 `app.py`, `template_omr.py`, `requirements.txt`, `reference/omr` 및 필요한 폴더들을 기존 GitHub 저장소의 최상위에 배치합니다. Streamlit 주 실행파일은 `app.py`입니다.

## 개인정보
Public GitHub에 학생 엑셀, OMR PDF, 성적 JSON, 비밀번호를 올리지 마십시오. Streamlit Secrets의 `APP_PASSWORD`를 사용하고, 세션 종료·클라우드 재시작에 대비해 백업하십시오.

## 검증 범위
문법 검사를 통과했으며, 기존 빈 OMR 양식에서 판독기가 정렬되는 기능을 기반으로 합니다. 실제 학생 마킹에 대한 완전한 검증은 아직 수행하지 않았습니다.
