THE PREMIUM · 3개년 등급 산정 및 탐구 누락 수정

1. GitHub thepremium 저장소의 app.py를 교체합니다.
2. reference/three_year_cuts.json, reference/thepremium-csat-3years.xlsx를 함께 교체합니다.
3. 새 버전은 기존 data/work.json의 학생 답안·원점수·월별 성적을 삭제하지 않습니다.
4. 서버에 남아 있는 3개년 등급컷의 공란에만 새 확인 원점수컷을 보완합니다. 직접 수정한 컷은 보존합니다.
5. 학생 성적표 메뉴의 '전체 학생 11월 정산 누락 진단'에서 탐구Ⅱ 등 원점수·등급의 누락 원인을 확인합니다.
6. 국가 공식 수능 국어·수학·탐구 등급은 표준점수 기준입니다. 본 등급은 입시기관 공개 원점수컷을 준용한 비공식 참고치입니다.
7. 윤리와 사상 2024학년도 2등급은 원자료에서 미표기되어 공란입니다. 국어·수학 2026학년도 5~8등급 원점수컷도 검증 전 공란입니다. 미검증값을 채우지 않습니다.
8. 국어·수학에서 한 학년도 컷이 비어 있어도 가능한 중앙값이 하나로 확정되면 해당 잠정등급을 표시합니다.
