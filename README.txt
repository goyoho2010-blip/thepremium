THE PREMIUM 3개년 수능 원점수 참고등급 판정 오류 수정

수정 범위: app.py의 possible_grades_from_year_cut() 함수만 교체.
기존 응시자 명부, 11월 OMR 판독·정답·배점, 3~10월 성적, PDF 양식은 변경하지 않습니다.

수정 이유: 특정 학년도 한 등급 경계값이 비어 있을 때 다른 확인된 경계값으로도 판정 가능한 등급을 미산출하는 오류.
예: 국어 화법과 작문 79점 -> 2024 2등급 / 2025 3등급 / 2026 3등급 => 중앙 3등급
    윤리와 사상 17점 -> 2024 7등급 / 2025 6등급 / 2026 6등급 => 중앙 6등급
